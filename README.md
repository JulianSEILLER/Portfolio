# 🚀 Portfolio - Julian SEILLER

Bienvenue sur le dépôt de mon portfolio personnel ! Ce site présente mon parcours, mes compétences ainsi que les différents projets sur lesquels j'ai travaillé, qu'ils soient personnels, scolaires (BTS SIO / BUT Informatique) ou professionnels.

🌍 **Lien du site en direct :** [https://portfolio-julianseiller.vercel.app/](https://portfolio-julianseiller.vercel.app/)

## ✨ Fonctionnalités

- 🌓 **Design Moderne & Responsive** : Interface fluide adaptée à tous les écrans (mobile, tablette, PC) avec des animations subtiles (Fade-in, ScrollReveal).
- 🇬🇧 **Bilingue (FR / EN)** : Support natif de l'anglais et du français avec un système de bascule fluide.
- 📂 **Présentation Dynamique des Projets** : Filtrage visuel par catégories (Projets Principaux, Stages, BTS, BUT) avec des cartes interactives.
- ✉️ **Formulaire de Contact** : Intégration avec EmailJS pour l'envoi de messages directement depuis le site.
- 📄 **Téléchargement de CV** : Bouton intégré pour récupérer facilement mon CV au format PDF.

## 🛠️ Stack Technique

Ce projet est développé sans framework lourd afin de garantir d'excellentes performances et un contrôle total sur l'interface :
- **HTML5** (Structure sémantique et accessibilité)
- **CSS3** (Variables CSS, Flexbox, Animations, Media Queries)
- **Vanilla JavaScript** (Logique d'interface, animations au clic/survol, EmailJS)
- **Hébergement** : [Vercel](https://vercel.com/)

## 🚀 Installation & Utilisation en local

Aucune installation complexe n'est requise. Pour lancer le projet en local :

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/JulianSEILLER/Portfolio.git
   ```
2. Ouvrez le dossier dans votre IDE préféré (ex: VSCode).
3. Lancez le fichier `index.html` dans votre navigateur (ou utilisez l'extension *Live Server* sur VSCode pour un rechargement automatique).
